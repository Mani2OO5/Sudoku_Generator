# Sudoku Generator 🧩

A small C++ project focused on experimenting with **Sudoku generation algorithms**.

## 🎯 Goal

The goal of this project was to design a **hybrid algorithm in C++** for generating a valid Sudoku board, followed by implementing a **recursive Sudoku solver**.

## 🚧 Project Status

The generation algorithm was not successfully completed, so the project did not reach the solving stage.

This repository is kept as part of my programming and algorithmic experiments. I may return to this project in the future and try a different approach to Sudoku generation.

## 🛠️ Built With

* C++
* Algorithm Design
* Recursion *(planned)*

> This project was created for learning and experimentation, so the current implementation may be incomplete or not fully functional.
